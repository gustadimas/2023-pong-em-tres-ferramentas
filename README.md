# Pong em três ferramentas

Projeto da faculdade, de set/2023 a nov/2023. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Fiz Pong três vezes em 2023, cada vez numa ferramenta. As versões em Python com Pygame (pasta `Pygame`, setembro) e em Godot 3 (pasta `Godot`, outubro) são um Pong com tema de futebol pra dois jogadores, com os mesmos sprites. Na de Godot o script em GDScript fica dentro da própria cena `main.tscn`.

Em novembro fiz em Construct 2 (pasta `Construct`) um Pong contra o computador, com menu e uma tela de como jogar.

## Como abrir

Pygame:

```
cd Pygame
pip install pygame
python main.py
```

Godot: abra o `Godot/project.godot` no Godot 3.x. O projeto é anterior ao Godot 4 e não abre direto nele.

Construct: o Construct 2 foi descontinuado, então o jeito mais fácil é arrastar o `Construct/Pong_Dimas.capx` pra dentro do Construct 3 no navegador (editor.construct.net), que importa projetos do Construct 2. A pasta `Construct/Pong_Dimas` é o mesmo projeto descompactado.
